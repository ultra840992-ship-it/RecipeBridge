# 이탈 고객 긴급 우회 대응 매뉴얼 (2026-07-25)

## 1. 개요
본 매뉴얼은 베타 서비스 가입 단계에서 발생하는 주요 이탈 지점, 특히 인증 코드 확인 대기 구간에서의 고객 불편을 최소화하고, 이탈 고객의 서비스 복귀를 유도하며, 제품 개선을 위한 피드백을 체계적으로 수집하기 위해 마련되었습니다.

## 2. 주요 이탈 지점 및 고통 지수 분석 결과
*   **이탈 지점**: 회원가입 시 인증 코드 확인 대기 구간
*   **이탈률**: 35% (가장 높은 이탈률 기록)
*   **고통 지수**: 인증 코드 수신 지연, 불확실한 대기 시간, 반복적인 시도 실패로 인한 피로감.

## 3. 이탈 고객 긴급 우회 대응 방안

### 3.1. 1:1 고객 문의 응대 가이드
*   **공감 및 문제 인지 안내**: 고객 문의 시, "회원가입 시 인증 코드 확인 과정에서 불편을 겪으셨군요. 현재 해당 구간의 이탈률을 인지하고 있으며, 더 원활한 가입 경험을 제공하기 위해 개선 작업을 진행 중입니다." 와 같이 공감하며 문제를 인지하고 있음을 명확히 전달합니다.
*   **임시 지원 방안 안내 (필요시)**:
    *   고객 동의 하에 CS 담당자가 수동으로 인증 절차를 돕거나, 보안 정책을 준수하는 범위 내에서 임시 계정 발급을 통한 서비스 선 체험 기회를 제공할 수 있습니다. (단, 보안팀 및 개발팀과 사전 협의 필수)
    *   "불편하시겠지만, 혹시 저희 CS팀에서 가입 절차를 직접 도와드리거나, 임시 계정을 통해 서비스를 먼저 경험해보실 수 있도록 지원해드릴까요?" 와 같이 제안합니다.
*   **개선 노력 강조**: "저희 개발팀(Bitz)에서 API 비동기 가입 절차를 간소화하여 더 빠르고 편리하게 가입하실 수 있도록 적극적으로 노력하고 있습니다." 라고 안내하여 고객의 이해를 구합니다.

*   **발송 대상**: 회원가입 중 인증 코드 확인 단계에서 이탈한 고객
