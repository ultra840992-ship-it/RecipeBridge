# 이탈 고객 긴급 우회 대응 매뉴얼 (회원가입 인증 지연)

## 1. 문제 정의 및 현황
베타 서비스 가입 퍼널 분석 결과, **회원가입 시 인증 코드 확인 대기 구간에서 35%의 가장 높은 이탈률**이 확인되었습니다. 이는 유저가 서비스 가입 과정에서 겪는 가장 큰 고통 지점 중 하나로 파악되며, 즉각적인 CS 개입이 필요한 Critical 이슈입니다.

## 2. 원인 분석 (잠정)
현재 인증 코드 발송 및 확인 절차의 시스템적 지연 또는 API 비동기 처리의 최적화 부족이 주요 원인으로 추정됩니다. 개발팀(Bitz)에는 API 비동기 가입 절차 간소화를 요청하여 근본적인 개선을 논의 중입니다.

## 3. 긴급 우회 대응 방안 (CS 시스템 동기화)
인증 코드 대기 구간에서 이탈하는 고객들을 위한 CS 긴급 우회 대응 절차를 다음과 같이 수립하여 CS 시스템에 동기화합니다.

### 3.1. 대응 트리거
*   **조건 1**: 고객이 인증 코드 발송 후 2분 이상 대기 상태 유지 (GA4 이벤트 추적 기반).
*   **조건 2**: 고객이 인증 코드 재발송을 2회 이상 요청했음에도 불구하고 가입을 완료하지 못했을 경우.
*   **조건 3**: 고객으로부터 직접 인증 코드 지연 관련 CS 문의가 접수된 경우.

### 3.2. CS 대응 절차
1.  **이탈 고객 감지**: GA4 추적 데이터를 통해 인증 코드 대기 중 이탈한 고객 리스트를 실시간으로 모니터링합니다. (필요시 수동 확인)
2.  **선제적 접근 (복귀 유도 이탈 메일 발송)**:
    *   조건 1, 2에 해당하는 고객에게는 가입 중단 후 5분 이내에 아래 명시된 복귀 유도 이메일을 자동 발송합니다.
    *   **메일 제목**: "[Carey] 회원가입에 어려움이 있으셨나요? 저희가 도와드릴게요!"
