# 이탈 고객 긴급 우회 대응 매뉴얼 (회원가입 인증 지연 문제)

## 1. 목적
회원가입 시 발생하는 인증 코드 확인 대기 구간의 높은 이탈률(35%)에 대한 긴급 CS 우회 대응 매뉴얼을 수립하고, CS 시스템에 동기화하여 고객 이탈을 최소화하고 서비스 사용 경험을 개선합니다.

## 2. 문제 정의 및 분석
*   **문제**: GA4 퍼널 분석 결과, 베타 서비스 회원가입 과정 중 '인증 코드 확인 대기' 구간에서 가장 높은 이탈률(35%)이 발생합니다. 이는 고객의 서비스 가입 초기 단계에서 심각한 고통을 유발하며, 서비스 이탈의 주요 원인이 됩니다.
*   **원인 (추정)**: API 비동기 처리 지연 또는 인증 시스템의 일시적 부하.
*   **현재 조치**: Bitz(개발) 팀에 API 비동기 가입 절차 간소화를 요청하였으며, 이는 장기적인 해결책으로 진행될 예정입니다.

## 3. 긴급 우회 대응 전략 (CS 액션 플랜)
기술적 개선이 완료되기 전까지, CS 관점에서 이탈 고객의 불편을 즉각적으로 해소하고 복귀를 유도하기 위한 다음과 같은 우회 대응 방안을 마련합니다.

### 3.1. 이탈 고객 감지 및 분류
*   **GA4 모니터링**: GA4 퍼널 분석 툴을 활용하여 '인증 코드 확인 대기' 단계에서 이탈하는 고객을 실시간으로 감지하고 목록화합니다.
*   **세그먼트 정의**: 인증 코드 입력 페이지 진입 후 5분 이상 대기 또는 페이지 이탈 시, '인증 지연 이탈 잠재 고객'으로 분류합니다.

### 3.2. 선제적 안내 및 지원
*   **자동 이탈 복귀 메일 발송**:
    *   기존 발행된 이탈 유저 복귀 리드메일 티켓을 활용하여, 인증 지연 이탈 잠재 고객에게 맞춤형 이메일을 발송합니다.
    *   **메일 내용 포함 사항**:
        *   인증 지연 문제에 대한 진심 어린 사과 및 상황 설명.
        *   현재 문제 해결을 위한 노력(Bitz 팀과의 협업) 안내.
        *   재시도 요청 (예: '다시 한번 시도해 주시겠어요?' 또는 '잠시 후 다시 시도해 주세요.')
        *   즉각적인 도움이 필요할 경우 1:1 CS 문의 채널(챗봇, 이메일, 전화) 안내.
        *   간단한 문제 해결 가이드 (예: 스팸함 확인, 네트워크 연결 확인 등).
*   **CS 챗봇/FAQ 업데이트**:
    *   CS 챗봇에 '회원가입 인증 지연' 관련 FAQ를 추가하고, 예상 소요 시간 및 대처 방안을 명확히 안내합니다.
    *   챗봇 상담 시, 인증 지연 관련 키워드 감지 시 해당 매뉴얼 기반의 답변을 우선 제공하도록 설정합니다.
*   **1:1 상담 시 가이드라인**:
    *   고객 문의 시, 문제 상황을 충분히 공감하고 신속하게 대응합니다.
    *   인증 코드를 수동으로 확인하거나, 대체 가입 절차를 안내할 수 있는지 개발팀(Bitz)과 협의하여 필요시 제공합니다. (단, 보안 및 시스템 부하를 고려하여 신중하게 접근)

### 3.3. 피드백 수집 및 제품 개선 연계
*   **복귀 고객 피드백 수집**: 우회 경로를 통해 성공적으로 가입을 완료한 고객들을 대상으로, 추가적인 불편 사항이나 개선 필요 사항에 대한 피드백을 적극적으로 수집합니다.
*   **데이터 기록**: 수집된 피드백은 `02_Wiki/decisions/` 경로에 기록하여 서비스 개선 백로그로 활용하고, 고통 지수를 정량화하여 우선순위를 설정합니다.
*   **기획팀(Nova) 연계**: Aegis 마스터를 통해 수집된 피드백과 고통 지수 분석 결과를 Nova(기획) 팀에 연계하여 다음 스프린트에 인증 절차 간소화 및 UX 개선 사항이 즉각 반영되도록 합니다.

## 4. CS 시스템 동기화
*   본 매뉴얼은 모든 CS 담당자가 접근하고 활용할 수 있도록 CS 시스템 내 매뉴얼 섹션에 등록합니다.
*   정기적인 교육을 통해 모든 CS 담당자가 매뉴얼 내용을 숙지하고 일관된 대응을 할 수 있도록 합니다.

## 5. 후속 조치
*   Bitz 팀의 API 개선 진행 상황을 지속적으로 모니터링하고, 개선 완료 시 본 긴급 우회 대응 매뉴얼을 업데이트 또는 폐기합니다.
*   우회 대응책 적용 후 이탈률 변화를 GA4를 통해 추적하고, 효과를 분석하여 매뉴얼을 보완합니다.
