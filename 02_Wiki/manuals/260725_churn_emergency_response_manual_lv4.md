# 이탈 고객 긴급 우회 대응 매뉴얼 (회원가입 인증 지연)

## 1. 개요
본 매뉴얼은 베타 서비스 회원가입 과정 중 '인증 코드 확인' 단계에서 발생하는 높은 이탈률(35%)에 대응하기 위한 CS 긴급 우회 절차를 명시합니다. 고객의 불편을 최소화하고 원활한 서비스 가입을 지원하여 이탈을 방지하는 것을 목표로 합니다.

## 2. 문제 정의
회원가입 시 SMS/이메일 인증 코드 발송 및 확인 대기 구간에서 시스템 지연으로 인해 고객이 가입을 중단하는 사례가 빈번하게 발생하고 있습니다. 이는 GA4 퍼널 분석 결과, 해당 구간에서 35%의 가장 큰 이탈률을 보이는 병목 지점으로 확인되었습니다.

## 3. 대응 절차

### 3.1. 고객 문의 접수 시 (인증 코드 미수신/지연)
1.  **상황 인지**: 고객이 인증 코드 미수신 또는 지연으로 인한 불편을 호소하는 경우.
2.  **즉각적인 사과 및 공감**: "가입 과정에서 불편을 드려 정말 죄송합니다. 인증 코드 수신이 원활하지 않아 많이 답답하셨으리라 생각됩니다. 고객님의 소중한 시간을 절약해 드리기 위해 최선을 다하겠습니다."
3.  **문제 확인**: 고객에게 가입 시도 시간, 입력 정보(휴대폰 번호/이메일 주소), 사용 환경(모바일/PC, 브라우저) 등을 간략히 확인합니다.
4.  **긴급 우회 방안 제시**:
    *   **옵션 1 (재시도 안내)**: "현재 일시적인 시스템 과부하로 인해 지연이 발생할 수 있습니다. 잠시 후 다시 시도해 주시거나, 혹시 다른 이메일 주소나 휴대폰 번호로 가입을 시도해 보시는 것은 어떠실까요?"
    *   **옵션 2 (수동 인증 지원)**: 고객 동의 하에, CS 담당자가 내부 시스템을 통해 고객의 가입 정보를 확인하고 수동으로 인증 처리 가능 여부를 개발팀(Bitz)에 문의 후 진행합니다. (고객 안내: "불편을 최소화하기 위해 저희가 직접 가입 정보 확인 후 빠르게 도와드리겠습니다. 잠시만 기다려 주시겠어요?")
    *   **옵션 3 (임시 계정 발급)**: (긴급 상황 및 시스템 복구 지연 시) 고객에게 임시 계정을 발급하여 서비스 이용을 먼저 시작할 수 있도록 안내합니다. "우선 서비스 이용을 먼저 시작하실 수 있도록 임시 계정을 발급해 드릴 수 있습니다. 추후 인증 문제가 해결되면 본 계정으로 전환을 도와드리겠습니다."
5.  **피드백 기록**: 해당 고객의 케이스를 CS 티켓에 상세히 기록하고, '인증 지연' 태그를 부여하여 통계 및 제품 개선에 활용합니다.

### 3.2. 이탈 고객 대상 복귀 마케팅 연계
1.  **이탈 고객 식별**: GA4 퍼널 분석을 통해 '인증 코드 확인' 단계에서 이탈한 고객 리스트를 주기적으로 추출합니다.
2.  **복귀 유도 메시지 발송**:
    *   **메일/메시지 제목**: "[Carey] 가입이 어려우셨죠? 지금 바로 해결해 드릴게요!" 또는 "잠깐! 회원가입 중 불편을 겪으셨나요?"
    *   **내용**: "안녕하세요, [고객 이름]님. 저희 서비스 가입 중 불편을 겪으신 점 깊이 사과드립니다. 특히 인증 코드 확인 과정에서 많은 분들이 어려움을 겪고 계심을 인지하고 있습니다. 현재 해당 문제 해결을 위해 노력 중이며, 혹시 아직 가입을 원하신다면 저희 CS팀에서 직접 도와드릴 수 있습니다. 아래 링크를 통해 문의 주시면 빠르게 가입을 완료하실 수 있도록 안내해 드리겠습니다. (CS 1:1 문의 링크 삽입)"
3.  **CS 채널 연결**: 복귀 유도 메시지에 CS 1:1 문의 채널 또는 전담 상담원 연결 링크를 포함하여 고객이 쉽게 도움을 요청할 수 있도록 합니다.

## 4. 후속 조치 및 피드백 루프
*   **개발팀(Bitz) 협의**: 인증 코드 API 비동기 처리 간소화 및 시스템 안정화를 위해 개발팀(Bitz)과 지속적으로 협의합니다. (참조: Bitz에게 API 비동기 가입 절차 간소화를 요청하기로 결정됨)
*   **Nova(기획팀) 연계**: 수집된 고객 피드백과 이탈 데이터를 Nova(기획)에 전달하여 회원가입 절차 개선 및 UI/UX 최적화 방안을 논의합니다.
*   **주기적인 매뉴얼 업데이트**: 시스템 개선 및 고객 피드백에 따라 본 매뉴얼을 주기적으로 업데이트합니다.
