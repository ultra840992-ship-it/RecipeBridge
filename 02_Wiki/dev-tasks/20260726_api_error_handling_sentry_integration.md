# [Critical] [Lv4] 결제/매칭 API 예외 처리 강화 및 실시간 에러 로그 센트리(Sentry) 연동 및 실서버 배포

## 1. 개요
결제 및 매칭 API의 안정성과 신뢰성 확보를 위해 예외 처리 로직을 강화하고, 실시간 에러 모니터링 시스템 Sentry를 연동하여 운영 중 발생하는 예외 상황에 대한 신속한 인지 및 대응 체계를 구축했다.

## 2. 작업 목표
*   결제 및 매칭 관련 핵심 API의 예외 처리 로직 견고화.
*   Sentry를 통한 실시간 에러 로깅 및 알림 시스템 구축.
*   에러 발생 시 디버깅에 필요한 컨텍스트 정보 자동 수집.
*   안정적인 실서버 배포.

## 3. 구현 내용

### 3.1. 관련 API 식별 및 예외 처리 강화
*   `live_server.py` 내 `payment_process`, `match_user`, `transaction_status` 등 핵심 결제 및 매칭 API 엔드포인트 식별 및 로직 분석 완료.
*   각 API 핸들러 및 내부 비즈니스 로직(DB 트랜잭션, 외부 결제 PG사 통신, 사용자 인증 등)에 대해 `try-except` 블록을 세분화하여 적용 완료.
*   네트워크 오류, 데이터 유효성 검사 실패, 외부 서비스 타임아웃 등 특정 예외 유형에 대한 명시적 핸들링 로직 추가 구현 완료.
*   사용자에게는 일반적인 오류 메시지를 반환하고, 내부 로그에는 상세한 스택 트레이스와 오류 코드를 기록하도록 구현 완료.
