### 결제/매칭 API 예외 처리 강화 및 Sentry 연동

**상태**: 진행 중 (In Progress)
**우선순위**: Critical (Lv4)

**개요**:
결제 및 매칭 API의 안정성을 최우선으로 확보한다. 예상 가능한 모든 예외 상황에 대한 처리를 강화하고, 실시간 에러 모니터링 및 알림을 위해 Sentry를 연동한다. 이를 통해 서비스 중단 없이 문제 발생 시 즉각적인 인지 및 대응이 가능하도록 시스템을 개선한다.

**작업 내용**:

1.  **Sentry SDK 연동**:
    *   `sentry-sdk` 라이브러리 설치 및 `live_server.py` 등 주요 서버 스크립트 초기화.
    *   Sentry DSN은 환경 변수(`SENTRY_DSN`)로 관리하여 보안 및 배포 유연성 확보.

2.  **결제/매칭 API 예외 처리 로직 강화**:
    *   **네트워크/외부 서비스 오류**: 결제 게이트웨이, 매칭 엔진 등 외부 API 호출 시 발생할 수 있는 네트워크 타임아웃, 연결 오류, 응답 코드 오류 등에 대한 `try-except` 블록을 명확히 정의.
    *   **비즈니스 로직 오류**: 잔액 부족, 유효하지 않은 결제 수단, 매칭 실패 조건 등 비즈니스 규칙 위반 시 발생하는 커스텀 예외를 정의하고 처리.
    *   **데이터 유효성 검증**: API 요청 데이터의 유효성 검증 로직을 강화하고, 유효하지 않은 데이터에 대한 예외 처리 추가.
    *   **로그 기록**: 모든 예외는 Sentry로 자동 전송되도록 설정하고, 필요시 `sentry_sdk.capture_exception()`을 명시적으로 사용하여 중요 오류를 기록.

3.  **검증 및 테스트**:
    *   `python -m py_compile` 실행하여 문법 오류 없음 확인.
    *   Sentry 연동 테스트: 의도적으로 예외를 발생시켜 Sentry 대시보드에서 실시간 로그 확인.
    *   API 시나리오 테스트: Postman 또는 자동화 테스트 스크립트를 통해 결제/매칭 API의 성공 및 다양한 오류 시나리오 (네트워크 단절, 잘못된 요청, 외부 서비스 오류 모의 등)를 테스트하여 예외 처리가 정상 작동하는지 검증.

4.  **실서버 배포**:
    *   변경 사항이 적용된 `live_server.py` 및 관련 설정 파일(환경 변수 포함)을 실서버에 배포.
    *   서비스 재시작 후 초기화 및 Sentry 연동 정상 작동 확인.

**예상 결과**:
*   결제/매칭 API의 안정성 및 견고성 대폭 향상.
*   실시간 에러 모니터링 시스템 구축으로 문제 발생 시 즉각적인 알림 및 대응 가능.
*   사용자 경험 저하 최소화 및 운영 효율성 증대.
