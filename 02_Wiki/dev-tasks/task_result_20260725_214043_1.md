3.  **능동적 지원 (CS 직접 개입)**:
    *   조건 3에 해당하는 고객 또는 이탈 메일 회신 고객에게는 CS 전문 컨설턴트가 즉시 1:1 채팅 또는 전화로 연결하여 문제를 해결합니다.
    *   **주요 조치**:
        *   인증 코드 재확인 및 수동 발송 지원.
        *   가입 절차 상세 안내 및 발생 가능한 문제점 선제적 설명.
        *   필요시 임시 계정 생성 지원 (Aegis 승인 하).
4.  **피드백 기록**: 모든 이탈 고객 대응 사례는 CS 티켓으로 상세히 기록하고, 해당 티켓에 `인증_지연_이탈` 태그를 부여하여 추후 분석 자료로 활용합니다.

## 4. 장기 개선 방안 (제품 피드백 연계)
*   **개발팀(Bitz) 요청**: API 비동기 가입 절차 간소화 및 인증 시스템 안정성 강화를 위한 최우선 개선 과제로 지정.
*   **기획팀(Nova) 연계**: 인증 절차 UX/UI 개선 및 대체 인증 방안 (예: 카카오/네이버 간편 로그인) 도입 검토 요청.

이 매뉴얼을 통해 고객님의 가입 이탈 경험을 최소화하고, 원활한 서비스 이용을 위한 최선의 지원을 제공할 것입니다.
