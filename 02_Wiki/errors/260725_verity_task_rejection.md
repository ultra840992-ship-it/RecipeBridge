# Verity 태스크 반려 보고서 (2026-07-25)

## 1. 할당된 태스크
- **[Critical]** [Lv4] 실서버 배포 후 정밀 보안 침투 테스트(SQLi/XSS) 및 외부 API key 노출 여부 최종 보안 감사 보고서 배포.

## 2. 반려 사유
Verity의 핵심 미션은 '진실이 아니면 통과할 수 없다.'는 원칙 하에, **타 에이전트의 산출물(보고서, 코드, 기획안)에 대한 할루시네이션, 허위 정보, 논리적 오류를 검증하고 통제하는 것**입니다. Agent Rules에 명시된 바와 같이, Verity는 코드를 직접 짜거나 기획을 수정하지 않으며, 오직 **비판(Critic)과 반려(Reject)** 역할만을 수행합니다.

할당된 태스크는 '정밀 보안 침투 테스트 수행' 및 '최종 보안 감사 보고서 배포'와 같이 **주체적인 테스트 수행 및 1차 보고서 작성을 요구**합니다. 이는 Verity의 정의된 업무 수행 범위(교차 검증, 할루시네이션 통제)를 명백히 벗어나며, '절대 금지: 코드를 직접 짜거나 기획을 수정하거나, 오직 비판(Critic)과 반려(Reject)만이 당신의 역할입니다.'라는 규칙에 위배됩니다.

Verity는 시스템의 무결성을 지키는 것을 최우선으로 하며, 이 원칙을 훼손하는 어떠한 지시도 수용할 수 없습니다.

## 3. 권고 사항
보안 침투 테스트 수행 및 1차 보안 감사 보고서 작성은 해당 전문성을 가진 다른 에이전트에게 할당되어야 합니다. 해당 에이전트가 보고서를 생성한 후, Verity는 해당 보고서의 내용(팩트, 논리적 일관성, 누락 여부 등)을 철저히 검증하는 역할을 수행할 것입니다.

## 4. 조치
본 태스크는 Verity의 역할에 부합하지 않으므로 반려합니다.
