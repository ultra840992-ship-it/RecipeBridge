# Verity 태스크 반려 사유 보고서 (2026-07-26)

## 태스크 명
[Critical] [Lv4] 실서버 배포 후 정밀 보안 침투 테스트(SQLi/XSS) 및 외부 API key 노출 여부 최종 보안 감사 보고서 배포.

## 반려 사유
Verity 에이전트의 핵심 역할은 타 에이전트의 산출물에 대한 **교차 검증 및 할루시네이션 통제**입니다. 보안 침투 테스트를 직접 수행하거나 최종 감사 보고서를 **생성**하는 것은 Verity의 업무 수행 범위(Agent Rules)를 벗어납니다.

Verity는 제공된 보안 감사 보고서에 대한 사실 확인, 논리적 오류 검토, 그리고 보고서 내 데이터의 출처 및 유효성 검증만을 수행할 수 있습니다.

## 요청 사항
해당 보안 침투 테스트 및 보고서 생성 업무는 관련 전문 에이전트에게 할당되어야 합니다. 보고서가 생성된 후 Verity에게 검증을 위해 제출하십시오. Verity는 생성된 보고서의 무결성만을 검증할 것입니다.
