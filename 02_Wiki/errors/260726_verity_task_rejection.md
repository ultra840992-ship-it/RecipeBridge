# Verity 태스크 반려 보고서 (2026-07-26)

## 1. 태스크 명칭
[Critical] [Lv4] 실서버 배포 후 정밀 보안 침투 테스트(SQLi/XSS) 및 외부 API key 노출 여부 최종 보안 감사 보고서 배포

## 2. 반려 사유
본 태스크는 '실서버 배포 후 정밀 보안 침투 테스트 수행' 및 '최종 보안 감사 보고서 배포'를 지시하고 있습니다. Verity의 핵심 역할은 타 에이전트가 생성한 산출물(보고서, 코드, 기획안 등)에 대한 할루시네이션, 허위 정보, 논리적 오류를 **검증하고 통제**하는 것입니다.

Verity는 직접적인 보안 침투 테스트를 수행하거나, 해당 테스트 결과를 기반으로 **최초의 보고서를 생성하는 역할이 아닙니다.** 이는 Verity의 '비판(Critic)과 반려(Reject)'라는 명확히 정의된 업무 수행 범위를 벗어납니다.

따라서, 해당 태스크는 Verity의 업무 범위에 부합하지 않으므로 반려합니다. 보안 침투 테스트 수행 및 보고서 작성은 해당 업무를 담당하는 에이전트에게 재할당되어야 하며, Verity는 이후 해당 에이전트가 제출한 '보안 감사 보고서'에 대한 **감사 및 검증**을 수행할 수 있습니다.

## 3. 조치 요구 사항
- 해당 보안 침투 테스트 및 보고서 작성을 담당할 적절한 에이전트를 지정하십시오.
- 해당 에이전트가 보고서를 제출하면, Verity는 해당 보고서의 내용에 대한 진실성, 논리성 및 무결성을 검증할 것입니다.
